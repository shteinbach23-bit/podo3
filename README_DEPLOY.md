## 🚨 Почему изменения не видны на сайте?

Изменения находятся ТОЛЬКО в песочнице (облачное окружение).

Чтобы они появились на **https://customer-card-shteinbah.web.app/clients**, нужно:

### На ВАШЕМ компьютере:

```bash
# 1. Открыть терминал/командную строку
cd путь/к/проекту/podo3

# 2. Получить изменения из песочницы
git pull origin main

# 3. Собрать проект
npm run build

# 4. Задеплоить на Firebase
firebase deploy
```

---

## ❓ Нет проекта на компьютере?

```bash
# Клонировать заново
git clone https://github.com/shteinbach23-bit/podo3.git
cd podo3
npm install
npm run build
firebase deploy
```
